# Contributing to alt-utils

Thank you for your interest in contributing to alt-utils anyone can contribute, and im more than happy if you are considering contributing!

Contributions are welcome if you are fixing a bug, improving existing code, adding a feature, improving documentation, or reporting an issue

## Getting Started

1. Fork the repository.
2. Clone your fork:
   ```sh
   git clone https://github.com/Real-Nigoat/alt-utils.git
   ```
3. Create a new branch for your changes:
   ```sh
   git checkout -b my-change
   ```
4. Make and test your changes.
5. Commit your changes with a clear commit message:
   ```sh
   git commit -m "Add support for ..."
   ```
6. Push your branch:
   ```sh
   git push origin my-change
   ```
7. Open a pull request against the main repository.

## Reporting Bugs

Before opening a bug report, check the existing issues to make sure the problem has not already been reported.

When reporting a bug, please include:

- A clear description of the problem
- Steps to reproduce it
- What you expected to happen
- What actually happened
- Your operating system
- Relevant logs or error messages
- Any other information that may help reproduce the issue

## Suggesting Features

Feature suggestions are welcome.

When opening a feature request, explain:

- What you want to add or change
- Why it would be useful
- How you think it should work

## Code Contributions

Keep changes focused on one feature or fix whenever possible.

Please:

- Keep the code readable
- Avoid unnecessary dependencies
- Test your changes before submitting them
- Do not include unrelated changes in the same pull request

## Pull Requests

When submitting a pull request:

- Give it a clear title
- Explain what your changes do
- Explain why the change is needed
- Mention any related issues
- Make sure the project still builds successfully

Pull requests may be reviewed and changes may be requested before they are merged.
